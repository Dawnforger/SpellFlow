# Desktop Handoff Bundle

This folder packages the current chat/workflow so you can continue in Cursor Desktop with minimal friction.

## Contents

- `CONVERSATION_HANDOFF.md`
  - Condensed timeline of what was requested and produced.
- `RESUME_PROMPT.md`
  - Copy/paste this prompt into Cursor Desktop to continue from current state.
- `grave_fiend_pack/`
  - Skeleton and complete educational reference files for the Grave Fiend glyph/aura system.

## How to use in Cursor Desktop

1. Open this repository/folder in Cursor Desktop.
2. Open and review:
   - `handoff/CONVERSATION_HANDOFF.md`
   - `handoff/grave_fiend_pack/README.md`
3. Paste `handoff/RESUME_PROMPT.md` into chat.
4. Continue implementation from the generated educational pack.
